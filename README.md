# MARS_CRISIS

## Public preprint

**When a Stable Pattern Is Not Yet an Effect:  
Specification Sufficiency, Operator-Reported LLM Corroboration, and Provenance in LLM Decision Benchmarks**

This repository contains the public preprint and bibliography for a controlled 15-run GPT-6 methods case study on specification sufficiency, provenance, and claim control in LLM evaluation.

The public conclusion is deliberately narrow: the protective decision was invariant across the observed 15-run corpus; individual-contact handling differed between the `K=16` condition and the `K≤12` conditions as represented in the manipulated prompts; no graded pattern was observed under the frozen rule; and a pre-specified threshold effect is not confirmed.
